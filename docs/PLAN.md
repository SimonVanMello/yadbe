# yadbe — Implementation plan

Statuses: ⬜ to do · 🟦 in progress · ✅ done.

One task = one sub-session = one or more Conventional Commits on the development branch (no PR for now). The master session breaks the work down, starts the sub-sessions, reviews their result and updates this file. A milestone ends with a manual validation by the product owner (checklist in `docs/validation/Mx.md`).

The **Session** column gives the model and effort the sub-session runs with: `opus` for design-heavy or risky backend work (drivers, concurrency, security, edit planning), `sonnet` for ports from yaggui and UI built on a frozen IPC contract. A task whose contract others depend on pushes the contract (Rust types + generated bindings + mock) first.

M2 and M3 are refined at the end of the previous milestone, once the base code is known.

M4-5 notes (Redis / Valkey, read): `Backend::KeyValue`, `KeyValueConnection { database, send, send_all }` over one multiplexed redis-rs connection (RESP3, RESP2 fallback), TLS and tunnel as the other engines. `db/keyvalue/` (reply model, `KvBytes`, redis-cli tokenizer, redaction of AUTH-like commands, command specs from `COMMAND INFO`) and the gate `session/keyvalue/gate.rs` (unsupported streaming / blocking commands, read-only from the server's flags plus scripts, PUBLISH, unknown and `admin` commands, dangerous commands with their measured effect, timeout, statement log / history). Open: not run in the real app; SSH tunnel and client certificate to Redis untested; Redis < 6 untested; front scrolling on 1M keys not measured; `postgres/tls.rs` should move to a shared module; the welcome text lists only SQL engines.

M4-2 notes (MongoDB, connection and browsing): `Backend::Document`, `DocumentConnection { execute(DocOp, ExecOptions, DocSender), kill(token), topology() }`. `db/document/`: `Json` (keeps key order), `DocOp` (one variant per operation, `display()` in shell form), `classify.rs` (read-only allow-list, dangerous kinds), `ejson.rs` (BSON ↔ `Value`; `Value::ObjectId` and `Value::Missing`; Int32 / Int64 kept by a type hint), field sampler, `MongoSettings` + URI parser. **The gate `session/document/gate.rs` is the only caller of the driver** (`run(GateContext, conn, GateRequest { op, origin, confirmed, max_time, token, max_documents }, sender) → Done | Confirm(DangerReport)`): the mongosh runtime and the edit path plug onto it.
